# 🎮 Jogo da Velha - Multiplayer Online

Um clássico jogo da velha com modo multiplayer online usando Firebase!

## ✨ Funcionalidades

- 🌐 **Multiplayer Online** - Jogue com amigos em qualquer lugar do mundo!
- 🤖 **Modo vs Computador** com IA usando algoritmo Minimax
- 👥 **Modo 2 Jogadores** local
- 📊 **Placar** de vitórias, derrotas e empates
- 🎯 **3 níveis de dificuldade**: Fácil, Médio e Impossível
- 📱 **Responsivo** - funciona em celulares, tablets e desktop

## 🌐 Como jogar Online

1. Acesse o jogo: [Jogar agora](https://ulissesaraujo.github.io/jogo-da-velha)
2. Clique em **"🌐 Jogar Online"**
3. **Para criar uma sala**: Clique em "➕ Criar Sala" e compartilhe o código
4. **Para entrar numa sala**: Digite o código e clique em "Entrar"
5. Quando os dois jogadores estiverem conectados, o jogo começa!

## 🎯 Como jogar Local

1. Clique em **"🎮 Jogar Local"**
2. Escolha entre jogar contra a IA ou 2 jogadores
3. Se jogar contra a IA, escolha a dificuldade
4. Clique nas células para fazer suas jogadas

## 🧠 Sobre a IA

A IA usa o **algoritmo Minimax**, que simula todas as jogadas possíveis e escolhe o melhor caminho. No nível "Impossível", a IA é imbatível!

## 🛠️ Tecnologias

- HTML5
- CSS3 (com animações e gradientes)
- JavaScript (ES6+)
- Firebase Realtime Database (multiplayer)
