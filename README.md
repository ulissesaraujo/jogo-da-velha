# 🎮 Jogo da Velha

Um clássico jogo da velha feito com HTML, CSS e JavaScript puro.

## ✨ Funcionalidades

- 🤖 **Modo vs Computador** com IA usando algoritmo Minimax
- 👥 **Modo 2 Jogadores** para jogar com amigos
- 📊 **Placar** de vitórias, derrotas e empates
- 🎯 **3 níveis de dificuldade**: Fácil, Médio e Impossível
- 📱 **Responsivo** - funciona em celulares, tablets e desktop

## 🎯 Como jogar

1. Acesse o jogo: [Jogar agora](https://seuusuario.github.io/jogo-da-velha)
2. Escolha o modo (vs Computador ou 2 Jogadores)
3. Se jogar contra a IA, escolha a dificuldade
4. Clique nas células para fazer suas jogadas
5. Tente fazer uma linha de 3 (horizontal, vertical ou diagonal)

## 🧠 Sobre a IA

A IA usa o **algoritmo Minimax**, que simula todas as jogadas possíveis até o fim do jogo e escolhe o melhor caminho. No nível "Impossível", a IA é imbatível — o máximo que você consegue é empatar!

## 🛠️ Tecnologias

- HTML5
- CSS3 (com animações e gradientes)
- JavaScript (ES6+)
